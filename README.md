#  Lenguajes Modernos de Programación

Repositorio de proyectos y prácticas desarrollados para la materia de **Lenguajes Modernos de Programación**, como parte de mi formación en la **Licenciatura en Ciencias Computacionales de la Universidad Autónoma de Nuevo León (UANL)**.

El objetivo de estos proyectos fue aplicar diferentes conceptos de programación y desarrollo de aplicaciones, principalmente utilizando **Python y Django**, además de trabajar con operaciones CRUD y la estructura de aplicaciones web.

##  Contenido del repositorio

El repositorio contiene diferentes ejercicios y proyectos realizados durante el curso.

###  CRUD

Proyecto enfocado en la implementación de las operaciones fundamentales para la administración de información:

- **Create:** creación de nuevos registros.
- **Read:** consulta y visualización de información.
- **Update:** modificación de registros existentes.
- **Delete:** eliminación de registros.

Este proyecto permitió poner en práctica el manejo y administración de datos desde una aplicación.

###  Django

Ejercicios y archivos relacionados con el aprendizaje y uso del framework **Django**, utilizando Python para el desarrollo de aplicaciones web.

###  MySite

Proyecto desarrollado con Django para aplicar la estructura de un sitio web, trabajando con los diferentes componentes que conforman una aplicación dentro del framework.

##  Ejecución del proyecto

Para ejecutar un proyecto desarrollado con Django es recomendable crear primero un entorno virtual.

### 1. Clonar el repositorio

```bash
git clone https://github.com/IdAle3/LMP-2132987.git
```

### 2. Acceder al proyecto

```bash
cd LMP-2132987
```

### 3. Crear un entorno virtual

```bash
python -m venv .venv
```

### 4. Activar el entorno virtual

En Windows:

```bash
.venv\Scripts\activate
```

### 5. Instalar Django

```bash
pip install django
```

### 6. Acceder al proyecto correspondiente

```bash
cd mysite
```

### 7. Ejecutar el servidor

```bash
python manage.py runserver
```

Una vez iniciado el servidor, la aplicación puede visualizarse desde el navegador utilizando la dirección local indicada por Django.
